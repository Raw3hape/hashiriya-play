# Vendored HUD fonts (SIL OFL 1.1)

Self-hosted slices from Google Fonts gstatic. Full CJK (kanji) is **not**
shipped — that is a future subsetting pass. Latin + Cyrillic + kana cover the
current HUD (English chrome, Cyrillic POI/location strings, Japanese kana).
